# نجّحني باك 🦊

تطبيق أندرويد لمراجعة البكالوريا الجزائرية مع التميمة فنّوك.

## ماذا يوجد في المشروع

| المجلد / الملف | المحتوى |
|---|---|
| `src/app.html` | كود التطبيق (الواجهة والمنطق) |
| `src/data/bac_data.json` | الشعب والمواد والمعاملات والمحاور وتاريخ الباك |
| `src/data/messages_ar.json` | رسائل فنّوك ونصوص الإشعارات |
| `src/mascot/` و `src/icons/` | فنّوك بأربع حالات وأيقونات التطبيق |
| `android/` | مشروع أندرويد الأصلي (Capacitor) |
| `android/.../IconSwitcher.java` | يغيّر أيقونة التطبيق على الشاشة حسب حالة فنّوك |
| `android/.../MoodWorker.java` | يفحص كل 3 ساعات ويغيّر الأيقونة حتى لو لم تفتح التطبيق |
| `tools/build_web.py` | يجمع التطبيق في `www/` مع الخطوط (يعمل بدون إنترنت) |
| `tools/make_icons.py` | يولّد أيقونات أندرويد وشاشة البداية من ملفات SVG |

## الطريقة 1: بناء APK على GitHub (بدون برامج على حاسوبك)

1. أنشئ حساباً مجانياً على github.com ثم مستودعاً جديداً (New repository) باسم `najahni-bac`.
2. ارفع كل ملفات هذا المشروع إلى المستودع (Upload files)، ما عدا مجلد `node_modules` إن وُجد.
3. افتح تبويب **Actions** في المستودع، ستجد عملية **Build APK** تشتغل وحدها (حوالي 5 إلى 8 دقائق).
4. عند انتهائها بعلامة ✓ خضراء، افتح العملية وحمّل الملف **najahni-bac-apk** من أسفل الصفحة.
5. فك الضغط، انقل `app-debug.apk` إلى هاتفك وثبّته (اسمح بالتثبيت من مصادر غير معروفة).

## الطريقة 2: Android Studio على حاسوبك

```bash
npm install
python3 tools/build_web.py
npx cap sync android
npx cap open android      # يفتح المشروع في Android Studio
```
ثم من Android Studio: **Build ▸ Build APK(s)**، أو وصّل هاتفك واضغط ▶️.
يحتاج Java 21 (موجودة مع Android Studio الحديث).

## بعد أي تعديل

- عدّلت الكود أو البيانات في `src/`؟ شغّل `npm run sync` (أو ارفع التعديل إلى GitHub فيُبنى APK جديد تلقائياً).
- عدّلت رسومات فنّوك أو الأيقونات؟ شغّل `python3 tools/make_icons.py` (يحتاج `rsvg-convert` و Pillow).
- أُعلن تاريخ الباك رسمياً؟ غيّر `estimated_start` و `official` في `src/data/bac_data.json`.

## كيف تعمل الأيقونة المتغيرة

- في `AndroidManifest.xml` أربع نسخ للأيقونة (activity-alias): سعيد، عادي، قلق، حزين. واحدة فقط مفعّلة.
- عند خروجك من التطبيق، وكل 3 ساعات في الخلفية، يحسب التطبيق حالتك:
  راجعت اليوم ← سعيد، لم تراجع بعد ← عادي ثم قلق بعد وقت التذكير، يوم غياب ← قلق، يومان فأكثر ← حزين.
- ملاحظة: بعض الهواتف (Xiaomi، Oppo، Realme...) تحتاج بضع ثوانٍ لتحديث الأيقونة، وقد تنقلها إلى آخر الشاشة. هذا سلوك الشركة المصنعة وليس خطأ.

## الإشعارات

يجدول التطبيق تذكيرات للأيام الـ14 القادمة في وقت التذكير الذي اخترته، وتذكيراً ثانياً على 21:30.
إذا راجعت اليوم يُلغى تذكير اليوم. إذا غبت عدة أيام تتغير الرسائل إلى رسائل "العودة".
على هواتف Xiaomi/Realme/Oppo: فعّل "التشغيل التلقائي" وألغِ "توفير البطارية" للتطبيق حتى تصل الإشعارات.

## قبل النشر على Google Play

1. أنشئ مفتاح توقيع (keystore) واحفظه جيداً، ثم ابنِ **Build ▸ Generate Signed Bundle (AAB)**.
2. حساب مطوّر Google Play (25 دولاراً مرة واحدة).
3. راجع المعاملات غير المؤكدة في تقرير البحث مع أستاذ أو كشف نقاط رسمي.
4. جرّب التطبيق 2-3 أسابيع مع مجموعة صغيرة من التلاميذ (اختبار مغلق).
